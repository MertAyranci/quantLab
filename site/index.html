Method

How a study runs, in order.

The order matters. Every step after the first is designed so the result can't be steered once it's visible.

  1. 01 · DISCOVER

    Find a candidate

    Explore development data freely. Anything found here is a lead, not evidence.

  2. 02 · PREREGISTER

    Write the kill rule

    Fix the signal, horizon, controls, sample gates and decision table as a contract in Git.

  3. 03 · FREEZE

    Lock the code

    Test the readout on synthetic data, then commit it with hashes. F19 shipped with 91 passing regression tests.

  4. 04 · COLLECT BLIND

    Gather unseen markets

    New markets register forward in time. Trade content stays unread until the cohort is complete.

  5. 05 · READ ONCE

    One invocation

    A create-only receipt binds the cohort, then the readout runs a single time. A crash is recorded, never retried.

  6. 06 · ACCEPT

    Keep the verdict

    No rescue, no retune, no extending the cohort. A new idea means a new study on new markets.

The machine

One small server in Helsinki, running since July.

A WebSocket collector and loader stream books into Postgres, cron jobs harvest resolutions, and every night the database is dumped, verified and shipped to Azure.
